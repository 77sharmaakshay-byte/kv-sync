Respondents filed the objection against the 
application filed under Order 41 Rule 27 of the Code 
of Civil Procedure, 1908. 
Heard. 
If any application is filed under Order 41 Rule 
27 of the Code of Civil Procedure in an appeal, it is 
incumbent on the part of the appellate court to 
consider the same at the time of hearing the appeal 
on merits so as to find out whether the proposed 
documents sought to be filed have any relevance in 
the issue involved and whether the application is 
bona fide. Therefore, put up the application under 
Order 41 Rule 27 of the Code of Civil Procedure with 
arguments of the parties on merits. 
Heard in-part.
Post this case on 17.08.2019 for remaining oral 
arguments in the daily cause list as a first case. 
Meanwhile, parties may file written arguments. 
Interim order dated 18.04.2017 is extended till 
tomorrow.

This is restoration application MCC 
No. 390 of 2020 moved by the petitioner to 
recall the order dated 08.09.2020 whereby 
the writ petition was dismissed for want of 
prosecution.
In view of the reasons indicated, 
restoration application is allowed. Order 
dated 08.09.2020 is hereby recalled. Writ 
petition is restored to its original number. 
Learned counsel for the State seeks 
and is granted one week’s and no more 
time to file counter affidavit.
Thereafter, one week’s time is granted 
to the petitioner to file the rejoinder 
affidavit.
List immediately thereafter.

# data branch (GitHub Actions likhta hai)

- `causelist/<DD-MM-YYYY>/` — Nainital HC ki us din ki cause list ka text (`*.txt`) aur `index.json`. PDFs mahine ki Release (`causelist-YYYY-MM`) mein.
- `state/known_ukhc_cnrs.txt.gz` — AWS data mein pehle se maujood Nainital HC cases ke CNR (scraper inhe dobara nahi laata).
- `state/done_ukhc_cnrs.txt` — scraper ne jo cases poore kar liye.
- `state/last_scrape` — scraper aakhri baar kis din chala.

Naye orders ki PDFs mahine ki Release (`live-YYYY-MM`) mein, har din ek `live-DD-MM-YYYY.tar.gz`.
